# Security

## Reporting a vulnerability

Email **security@kowloon.network**. Please don't open a public issue,
pull request or post about it until we've had a chance to fix it.

Tell us:

- what the problem is and what someone could do with it;
- how to reproduce it (steps, requests, or a small proof of concept);
- which part it affects (server, web, app or client library) and which version
  or commit, if you know.

We'll reply within a week to confirm we've got it, keep you posted while we
work on a fix, and credit you when it ships unless you'd rather we didn't.

Kowloon is a small project with no bug bounty. We can't pay for reports, but
we're genuinely grateful for them.

## What's in scope

The code in the kowloon-network repositories: the server, the web frontend,
the mobile app and the client library. For a problem with a particular server
someone else runs, contact that server's admin as well.

Please test only against your own installation or accounts you control. Don't
access other people's data, and don't disrupt servers other people rely on.

## Supported versions

Fixes go into the latest release. Server admins should keep up to date.
